Cấu Hình Tự Động Hóa & Webhook

Chế độ Automation tự động quét các ảnh mới trong thư mục chỉ định, tạo mô hình tượng 3D tối ưu cho app tô tượng, và tự động gửi file GLB đến Webhook API của bạn.

Hệ thống sẽ quét các file .png, .jpg, .webp mới thả vào đây.
Các file GLB và gói ZIP hoàn chỉnh sẽ được lưu tại đây.
Hệ thống sẽ gửi HTTP POST kèm link tải GLB và metadata tượng.
